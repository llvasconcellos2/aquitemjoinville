Calça Cintura Baixa
Escrito por Administrator   
12-Dec-2008
Se você é magra, tem quadris pequenos e sem barriga tem o corpo ideal para usar uma calça saint-tropez (ou de cintura baixa).
O cós mais baixo cria uma linha horizontal, aumentando o quadril.
Caso tenha quadris largos ou barriguinha saliente este modelo só servirá para evidenciar o que não quer, e a calça funcionará como um aparador de barriga.
